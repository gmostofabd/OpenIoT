\# Blink Example



\## Overview



This example demonstrates how to initialize the OpenIoT Framework and blink the onboard LED.



\## Hardware



\- ESP32 Development Board

\- USB Cable



\## Wiring



| Signal | Pin |

|---------|----:|

| LED | GPIO2 |



\## Expected Output



\- LED blinks every 500 ms.

\- Framework initializes successfully.

\- Serial Monitor displays startup messages.
